STANDBY ДЛЯ SAMSUNG (ANDROID) - СПИСОК ФУНКЦИЙ

=== УСТРОЙСТВО И СТЕК ===
Телефон: Samsung Galaxy A56 5G (SM-A566E/DS), One UI 9, Android 17 (уточнить)
minSdk 34, targetSdk 36
Kotlin + Jetpack Compose, Android Studio

=== ОСНОВА ===
1. DreamService (заставка) - запуск при зарядке и погасшем экране
2. Kotlin + Jetpack Compose
3. Только горизонтальная ориентация (landscape), портрет не нужен
4. Настройки: DataStore (страницы, стиль часов, источники данных)

=== ЛЕВАЯ КОЛОНКА: ВРЕМЯ И ДАТА ===
5. Часы, минуты, секунды отдельными крупными блоками
6. Анимация смены цифр
7. День недели
8. Число
9. Месяц
10. Год

=== ЦЕНТР: ЗАДАЧИ ===
11. Список задач со свайпом
12. Заголовок задачи
13. Описание полностью или со скроллингом (verticalScroll)
14. Дата создания задачи
15. Дата изменения задачи
16. Отметка "выполнено" одним тапом
17. Источник: Google Tasks API или свои заметки в Room
18. Дата создания хранится в Room (в Google Tasks API её нет)
19. Быстрое добавление через Share to (Intent)

=== ПРАВАЯ КОЛОНКА: КАЛЕНДАРЬ ===
20. Мини-календарь месяца
21. Точки на днях с событиями
22. События на сегодня и завтра
23. Источник: CalendarContract (разрешение READ_CALENDAR)

=== GOOGLE KEEP И SAMSUNG NOTES ===
24. Публичного API Keep для обычных аккаунтов нет
25. Вариант 1: официальный виджет Keep через AppWidgetHost (в DreamService может работать нестабильно, проверить)
26. Вариант 2: Google Tasks (кастомный дизайн)
27. Вариант 3: свои заметки в Room
28. Samsung Notes: публичного API для чтения нет, только через Share to или свои заметки в Room

=== ДОПОЛНИТЕЛЬНЫЕ ФУНКЦИИ ===
29. Погода (Open-Meteo, без ключа): температура, иконка, прогноз по часам
30. Управление музыкой: обложка, трек, пауза, следующий (MediaSessionManager, нужен доступ к уведомлениям через NotificationListenerService)
31. Заряд батареи и время до полной зарядки
32. Ночной режим: затемнение по датчику света, красные цифры
33. Защита AMOLED: сдвиг картинки раз в минуту, чёрный фон
34. Переключение страниц свайпом, как в iOS StandBy

=== РАЗРЕШЕНИЯ ===
35. INTERNET (погода)
36. READ_CALENDAR (календарь, запрос в рантайме)
37. Доступ к уведомлениям (управление музыкой)

=== ВАЖНО ДЛЯ SAMSUNG ===
38. Отключить оптимизацию батареи для приложения
39. Кнопка в приложении, открывающая настройки заставки
40. Автоповорот включить заранее
