# Правила: язык

- Язык приложения определяется только двумя способами:
  1. по системному языку телефона (по умолчанию);
  2. по языку, который я выбрал в настройках приложения.
- Никаких других источников (по IP, по геолокации, по региону SIM) использовать нельзя.
- Выбор языка в приложении: Per-App Language (`LocaleManager`, `android:localeConfig`), minSdk 34 это поддерживает.
- Поддерживаемые языки: ru, en, uz (поправь список, если нужно). Если системный язык не поддерживается, используется en.
- Все строки только в `res/values*/strings.xml`: `values` (en, по умолчанию), `values-ru`, `values-uz`.
- Даты, месяцы, дни недели форматировать через `java.time.format.DateTimeFormatter` с `Locale.getDefault()`, не писать названия вручную.
- Жёстко заданные `Locale.US`, `Locale("ru")` и подобные запрещены.
- Единицы погоды (°C/°F) выбираются по системной локали или по выбору в настройках.
