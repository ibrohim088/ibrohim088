# Правила: погода

- Источник данных: Open-Meteo, без API-ключа. Другие погодные сервисы не использовать.
- Разрешённые хосты: `api.open-meteo.com`, `geocoding-api.open-meteo.com`. Другие сетевые запросы запрещены.
- Место: либо последняя известная геолокация телефона, либо город, выбранный в настройках. Больше никаких источников.
- Что показывать: текущая температура, иконка, прогноз по часам. Единицы по `rules/localization.md`.
- Иконка выбирается по weather code Open-Meteo, набор иконок по `rules/icons.md`.
- Кэш: хранить последний ответ (DataStore), обновлять не чаще раза в 30 минут.
- Нет сети или ошибка: показывать последние сохранённые данные с временем обновления, без всплывающих ошибок на заставке.
- Запросы идут только пока заставка активна, фонового опроса нет.
- Таймаут запроса 10 секунд, всё в корутинах, не на главном потоке.
