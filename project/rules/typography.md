# Правила: шрифты и текст

- Шрифт по умолчанию: системный (`FontFamily.Default`).
- Другой шрифт можно использовать только если он указан в списке ниже. Сейчас список пуст.
  - Разрешённые доп. шрифты: нет
- Подключать шрифты из интернета (Google Fonts и т.п.) нельзя. Если нужен свой шрифт, он кладётся в `res/font/` и добавляется в список выше.
- Цифры часов: моноширинные (`fontFeatureSettings = "tnum"`), чтобы время не дёргалось при смене цифр.
- Размеры текста только в `sp`, значения хранятся в одном месте (`Type.kt`), не разбросаны по экранам.
- Весь текст берётся из `strings.xml`, строк внутри Composable быть не должно.
