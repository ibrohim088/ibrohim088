# Правила: иконки

- Источник иконок: **УКАЖИ ССЫЛКУ** (замени эту строку, пока ссылки нет, иконки не добавлять).
- Использовать только иконки из этого источника. Другие библиотеки иконок, эмодзи вместо иконок и самодельные иконки запрещены.
- Формат: Vector Drawable (`res/drawable/ic_*.xml`) или SVG, сконвертированный в Vector Drawable.
- Имена файлов: `ic_<название>.xml`, строчными буквами, слова через `_` (например, `ic_battery_charging.xml`).
- Цвет иконок задаётся через `tint` в Compose, а не внутри файла. На AMOLED иконки светлые на чёрном фоне.
- Иконка погоды выбирается по коду погоды Open-Meteo, набор иконок тоже только из источника выше.
- Нужной иконки нет в источнике: не рисовать свою, а сказать мне, какая нужна.
