# StandBy for Samsung

Android-приложение, повторяющее iPhone StandBy на Samsung (AMOLED): экран-заставка с часами, календарём и задачами.
Источник истины по функциям: `Standby.txt` в этой папке. Читай его перед любой работой.

## Устройство и стек
- Телефон: Samsung Galaxy A56 5G (SM-A566E/DS), One UI 9, Android 17 (уточнить)
- Kotlin, Jetpack Compose, DreamService, DataStore, Room
- minSdk 34, targetSdk 36
- Основной режим: landscape. Портрет не нужен.

## Правила ответов
- Отвечай кратко и по делу, без лишних объяснений.
- Код отдавай полными файлами целиком, не диффами, с путём к каждому файлу.
- Если меняется несколько файлов, отдавай только изменённые.
- Не меняй то, что не просили менять.
- Не добавляй функции, которых нет в `Standby.txt`.
- Явно не нужны: слайдшоу, таймер, будильник, уведомления, курсы валют, виджеты.
- Язык ответов: русский. Код и комментарии в коде: английский.

## Правила проекта (читать перед написанием кода)
- `rules/icons.md`: иконки только из указанного источника.
- `rules/typography.md`: системный шрифт, текст только из `strings.xml`.
- `rules/localization.md`: язык только системный или выбранный в приложении.
- `rules/weather.md`: Open-Meteo, кэш, разрешённые хосты.

## Скрипты
- `scripts/check-rules.ps1`: проверка кода на нарушения правил. После изменений кода запускай:
  `.\scripts\check-rules.ps1 -Root <путь к app\src\main>`
  и исправляй всё, что он находит.

## Ограничения платформы (не обходить, а учитывать)
- Публичного API Google Keep для обычных аккаунтов нет. Варианты: виджет Keep, Google Tasks, свои заметки в Room.
- Публичного API чтения Samsung Notes нет.
- Музыка (MediaSessionManager) требует доступ к уведомлениям через NotificationListenerService.
- Дата создания задачи в Google Tasks API отсутствует, хранить в Room.
